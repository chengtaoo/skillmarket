命令行工具 (CLI)

如果你安装了 clawhub CLI，可以使用以下命令：

# 添加私有市场
clawhub add-market http://your-server:3000
# 搜索技能
clawhub search keyword
# 安装技能
clawhub install skill-slug
# 发布技能
clawhub publish ./my-skill
